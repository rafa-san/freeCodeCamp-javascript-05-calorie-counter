# JavaScript Algorithms and Data Structures Certification #05 | Calorie Counter

## 1️⃣ Objetivo
Desenvolver um contador de calorias e aprender a manipular dados fornecidos pelo usuário.

## 2️⃣ Descrição
Este é o quinto curso da trilha **JavaScript Algorithms and Data Structures Certification**.

O projeto explora conceitos fundamentais para interações dinâmicas com o usuário, como:

- Validação de entradas;
- Realização de cálculos baseados em dados do usuário;
- Atualização dinâmica da interface para exibir resultados.

Além disso, aprenderemos:

- O uso básico de expressões regulares para validação;
- A aplicação do método addEventListener() para capturar eventos.

## 3️⃣ Principais Modificações
Criei uma página HTML para registrar informações importantes do tutorial e um arquivo CSS para personalizá-la.
