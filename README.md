# freeCodeCamp

## JavaScript Algorithm and Data Structures Certification #05

### Calorie Counter

O objetivo deste curso é trabalhar com dados fornecidos pelo usuário.

Neste projeto chamado contador de calorias, iremos aprender a validar a entrada do usuário, realizar cálculos com base nessa entrada e atualizar dinamicamente sua interface para exibir os resultados.

De forma prática aprenderemos a trabalhar, por exemplo, com expressões regulares básicas e a utilizar o método addEventListener().
